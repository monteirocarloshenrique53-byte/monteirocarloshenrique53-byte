## 🎮 Sobre mim

Sou um **analista de dados especializado no cenário competitivo de League of Legends**. Transformo dados de partidas profissionais em análises visuais, insights estratégicos e dashboards interativos — tudo isso por paixão genuína pelo jogo e pelo esporte eletrônico brasileiro.

Atualmente construindo meu portfólio de análises independentes, com foco em:

- 📊 Dashboards interativos de performance individual e coletiva
- 🔍 Análise de métricas avançadas (EGR, MLR, GSPD%, DPM, VSPM)
- 🏆 Acompanhamento de campeonatos nacionais (CBLOL, CD, VCT)
- 💡 Storytelling com dados — transformar números em narrativas que fazem sentido para a comunidade gamer
